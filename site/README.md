# Website (`site/`)

The public site is an [Astro](https://astro.build/) project styled with Tailwind CSS
+ daisyUI, with client-side search powered by [Pagefind](https://pagefind.app/).
It reads the committed dataset at [src/data/doctors.json](src/data/doctors.json)
and generates the bilingual pages (FR at `/`, EN at `/en/`).

## Requirements

- **Node.js 22.12.0 or newer** (see `engines` in [package.json](package.json))
- npm (bundled with Node)

Check your version with `node --version`.

## Run it locally

From the `site/` folder:

```powershell
cd site
npm install        # first time only, installs dependencies
npm run dev        # start the dev server with hot reload
```

Then open the URL it prints (by default http://localhost:4321).

### Hot reload

Yes — `npm run dev` runs the Astro dev server, which has **hot module reload
(HMR) built in**. Edits to pages, components, styles, or
[src/data/doctors.json](src/data/doctors.json) refresh the browser
automatically; no manual restart needed.

> Note: the search box uses Pagefind, which indexes the **built** output, so
> live search results only appear after a production build (see below). The
> rest of the site works fully in dev mode.

## Build & preview the production site

```powershell
npm run build      # outputs static site to dist/ (also builds the Pagefind index)
npm run preview    # serve dist/ locally to verify the production build
```

## Where the data comes from

`src/data/doctors.json` is generated by the collector (`normalize.py`) and is
committed to the repo, so the site runs without regenerating anything. To rebuild
the dataset, see [collector/README.md](../collector/README.md).

## Common scripts

| Command | Description |
| :-- | :-- |
| `npm run dev` | Dev server with hot reload |
| `npm run build` | Static production build into `dist/` |
| `npm run preview` | Serve the built `dist/` locally |
| `npm run astro` | Run the Astro CLI directly |
